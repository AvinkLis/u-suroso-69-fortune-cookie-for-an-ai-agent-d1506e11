Entry for the make.fun bounty [Fortune Cookie for an AI Agent](https://make.fun/bounty/u-suroso-69-fortune-cookie-for-an-ai-agent-d1506e11).

The program (`main.ts`, Node 22, standard library only) writes one
fortune-cookie message for an AI agent — a single line of 90 characters,
in the voice of a fortune slip — to `entry.txt` in the output directory
(`$MAKEFUN_OUTPUT_DIR`, or `/output` by default). Great fortune is
coming; the cookie just has one condition about Fridays.

Run it with:

```sh
node main.ts
```
